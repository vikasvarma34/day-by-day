Deep TLS View — Phase 3 Real Byte & Key Analysis

Cryptographic Key Roles

Certificate Public/Private Key
Used exclusively for authentication during initial TLS setup to verify server identity. Does not encrypt individual HTTP requests.
TLS Traffic Secrets
Temporary master secrets generated and negotiated strictly for this specific connection.
Symmetric Application Keys
Derived from traffic secrets via HKDF-Expand-Label to provide fast, authenticated symmetric payload encryption (e.g. AES-GCM).
