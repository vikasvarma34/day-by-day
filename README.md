# Day by Day

Day by Day is a small Android-only personal planner designed for one user.

## Repository Layout
* `android/` - Android application codebase (Jetpack Compose, Kotlin)
* `backend/` - Node.js + TypeScript Express backend codebase
* `docs/` - Project documentation

> **Note**: Both Android and backend baseline projects are scaffolded and buildable.

For detailed architecture, technology stack decisions, build commands, and product requirements, please refer to:
* [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md)
* [docs/requirements.md](docs/requirements.md)
